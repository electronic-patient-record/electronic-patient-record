اپنی بنائی ہوئی چیز شیئر کریں: یہاں میچر ایک ایسا ریکارڈ سمجھا رہا ہے جسے وہ نہ جوڑتا

یہ زمرہ ان چیزوں کے لیے ہے جو آپ نے Electronic Patient Record کے ساتھ یا اس کے گرد بنائیں: انضمام، اسکرپٹس، ڈیمو، رہنما اور تجربات۔ شکل دکھانے کے لیے، یہ ایک چھوٹی سی چیز ہے جو منصوبہ پہلے سے کرتا ہے۔

## یہ کیا ہے

میچر (matcher) ایک Rust لائبریری ہے جو مریض کی شناخت کے دو ریکارڈ کا موازنہ کرتی ہے اور ہر خانے کے لحاظ سے بتاتی ہے کہ وہ انھیں کیوں جوڑے گی یا نہیں جوڑے گی۔

## یہ کیوں ہے

دو مختلف لوگوں کے دو ریکارڈ جوڑنے سے ان کی طبی تاریخیں مل جاتی ہیں، اور اس سے دونوں کو نقصان ہو سکتا ہے۔ اس لیے میچر کبھی خاموشی سے فیصلہ نہیں کرتا۔ غائب خانہ غائب کے طور پر بتایا جاتا ہے، کبھی مطابقت نہیں گنا جاتا، اور کچھ خلا خودکار جوڑ کو سیدھا روک دیتے ہیں۔

## آزمائیں

دو فرضی ریکارڈ: ایک ہی خاندانی نام اور تاریخِ پیدائش، لیکن دوسرے میں پہلا نام نہیں۔

```sh
git clone https://github.com/electronic-patient-record/electronic-patient-record.git
cd electronic-patient-record/electronic-patient-record-matcher-with-rust
echo '{"names":[{"family":"Rivera","given":["Alex"]}],"birth_date":"1980-04-12","sex":"female"}' > a.json
echo '{"names":[{"family":"Rivera","given":[]}],"birth_date":"1980-04-12"}' > b.json
cargo run -- a.json b.json
```

آؤٹ پٹ کا ایک حصہ:

```json
{
  "score": 1.0,
  "decision": "review",
  "fields": [
    { "field": "family_name", "similarity": 1.0, "weight": 0.25, "note": "similarity 1.00" },
    { "field": "given_name", "similarity": null, "weight": 0.2, "note": "no given name on one or both records" },
    { "field": "birth_date", "similarity": 1.0, "weight": 0.3, "note": "similarity 1.00" }
  ],
  "conflicts": [ "given name not available to confirm the link" ]
}
```

## جس نے مجھے حیران کیا

دونوں ریکارڈ کے تمام مشترک خانے ملتے ہیں، اس لیے اسکور 1.0 ہے، اور پھر بھی میچر انھیں جوڑنے سے انکار کرتا ہے۔ وہ انھیں کسی انسان کے پاس بھیجتا ہے، کیونکہ غائب پہلا نام کبھی جوڑ کی تصدیق نہیں کر سکتا۔ اونچا اسکور اکیلا کافی نہیں۔

حدیں توثیق شدہ نہیں، اور سافٹ ویئر طبی استعمال کے لیے نہیں۔

## اپنا شیئر کریں

جو آپ نے بنایا اسے یہاں نئی گفتگو میں پوسٹ کریں، ساتھ:

- یہ کیا ہے، ایک جملے میں؛
- آپ نے اسے کیوں بنایا؛
- دیکھنے کے لیے کچھ: ایک ٹکڑا، اسکرین شاٹ یا لنک؛
- کوئی اور اسے کیسے آزما سکتا ہے؛
- آپ کس قسم کی رائے چاہتے ہیں۔

صرف فرضی ریکارڈ استعمال کریں، کبھی مریضوں کا اصل ڈیٹا نہیں۔ اور اگر آپ کسی اور کے کام پر بنا رہے ہیں تو ان کا حوالہ دیں۔
