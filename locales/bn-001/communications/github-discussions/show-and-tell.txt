আপনার বানানো জিনিস ভাগ করুন: এখানে ম্যাচার এমন একটি রেকর্ড ব্যাখ্যা করছে যা সে যুক্ত করত না

এই বিভাগ Electronic Patient Record দিয়ে বা তার চারপাশে আপনি যা বানিয়েছেন তার জন্য: ইন্টিগ্রেশন, স্ক্রিপ্ট, ডেমো, টিউটোরিয়াল ও পরীক্ষা। ধরনটি দেখাতে, প্রকল্প ইতিমধ্যে যা করে তার একটি ছোট উদাহরণ এখানে।

## এটি কী

ম্যাচার (matcher) একটি Rust লাইব্রেরি, যা দুটি রোগীর পরিচয় রেকর্ড তুলনা করে এবং ক্ষেত্র ধরে ধরে বলে কেন সে সেগুলো যুক্ত করত বা করত না।

## কেন এটি আছে

ভিন্ন দুজন মানুষের দুটি রেকর্ড যুক্ত করলে তাঁদের চিকিৎসার ইতিহাস মিশে যায়, এবং তাতে দুজনেরই ক্ষতি হতে পারে। তাই ম্যাচার কখনও নীরবে সিদ্ধান্ত নেয় না। অনুপস্থিত ক্ষেত্র অনুপস্থিত বলে জানানো হয়, কখনও মিল হিসেবে গোনা হয় না, এবং কিছু ফাঁক স্বয়ংক্রিয় যুক্তকরণকে সরাসরি আটকে দেয়।

## চেষ্টা করুন

দুটি বানানো রেকর্ড: একই পারিবারিক নাম ও জন্মতারিখ, কিন্তু দ্বিতীয়টির প্রথম নাম নেই।

```sh
git clone https://github.com/electronic-patient-record/electronic-patient-record.git
cd electronic-patient-record/electronic-patient-record-matcher-with-rust
echo '{"names":[{"family":"Rivera","given":["Alex"]}],"birth_date":"1980-04-12","sex":"female"}' > a.json
echo '{"names":[{"family":"Rivera","given":[]}],"birth_date":"1980-04-12"}' > b.json
cargo run -- a.json b.json
```

আউটপুটের একটি অংশ:

```json
{
  "score": 1.0,
  "decision": "review",
  "fields": [
    { "field": "family_name", "similarity": 1.0, "weight": 0.25, "note": "similarity 1.00" },
    { "field": "given_name", "similarity": null, "weight": 0.2, "note": "no given name on one or both records" },
    { "field": "birth_date", "similarity": 1.0, "weight": 0.3, "note": "similarity 1.00" }
  ],
  "conflicts": [ "given name not available to confirm the link" ]
}
```

## যা আমাকে অবাক করেছে

দুটি রেকর্ডের সমস্ত অভিন্ন ক্ষেত্র মেলে, তাই স্কোর 1.0, তবু ম্যাচার সেগুলো যুক্ত করতে রাজি হয় না। সে সেগুলো একজন মানুষের কাছে পাঠায়, কারণ অনুপস্থিত প্রথম নাম কখনও যুক্তকরণ নিশ্চিত করতে পারে না। শুধু উঁচু স্কোরই যথেষ্ট নয়।

সীমাগুলো যাচাই করা হয়নি, এবং সফটওয়্যারটি ক্লিনিক্যাল ব্যবহারের জন্য নয়।

## আপনারটি ভাগ করুন

আপনি যা বানিয়েছেন তা এখানে একটি নতুন আলোচনায় পোস্ট করুন, সঙ্গে:

- এটি কী, এক বাক্যে;
- কেন বানিয়েছেন;
- দেখার মতো কিছু: একটি স্নিপেট, স্ক্রিনশট বা লিংক;
- অন্য কেউ কীভাবে চেষ্টা করতে পারে;
- কী ধরনের প্রতিক্রিয়া চান।

শুধু বানানো রেকর্ড ব্যবহার করুন, কখনও প্রকৃত রোগীর তথ্য নয়। আর অন্য কারও কাজের ওপর ভিত্তি করলে তাঁকে কৃতিত্ব দিন।
