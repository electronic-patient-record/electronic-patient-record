شاركوا ما بنيتموه: هنا يشرح المطابِق سجلًّا لن يربطه

هذه الفئة لما صنعتموه مع Electronic Patient Record أو حوله: تكاملات ونصوص برمجية وعروض توضيحية وشروحات وتجارب. لإظهار الشكل، إليكم شيئًا صغيرًا يفعله المشروع بالفعل.

## ما هو

المطابِق (matcher) مكتبة Rust تقارن سجلَّي هوية مريضين وتقول، حقلًا بحقل، لماذا كانت ستربطهما أو لا.

## لماذا يوجد

ربط سجلَّين لشخصين مختلفين يخلط تاريخيهما الطبيين، وهذا قد يضر بكليهما. لذلك لا يقرر المطابِق أبدًا بصمت. يُبلَّغ عن الحقل المفقود على أنه مفقود، ولا يُحسب أبدًا اتفاقًا، وبعض الفجوات تمنع الربط التلقائي منعًا تامًّا.

## جرّبوه

سجلان مختلقان: اللقب نفسه وتاريخ الميلاد نفسه، لكن الثاني بلا اسم أول.

```sh
git clone https://github.com/electronic-patient-record/electronic-patient-record.git
cd electronic-patient-record/electronic-patient-record-matcher-with-rust
echo '{"names":[{"family":"Rivera","given":["Alex"]}],"birth_date":"1980-04-12","sex":"female"}' > a.json
echo '{"names":[{"family":"Rivera","given":[]}],"birth_date":"1980-04-12"}' > b.json
cargo run -- a.json b.json
```

جزء من المخرجات:

```json
{
  "score": 1.0,
  "decision": "review",
  "fields": [
    { "field": "family_name", "similarity": 1.0, "weight": 0.25, "note": "similarity 1.00" },
    { "field": "given_name", "similarity": null, "weight": 0.2, "note": "no given name on one or both records" },
    { "field": "birth_date", "similarity": 1.0, "weight": 0.3, "note": "similarity 1.00" }
  ],
  "conflicts": [ "given name not available to confirm the link" ]
}
```

## ما فاجأني

كل حقل يشترك فيه السجلان متفق، فالدرجة 1.0، ومع ذلك يرفض المطابِق ربطهما. يحيلهما إلى إنسان، لأن غياب الاسم الأول لا يمكن أن يؤكد الربط أبدًا. الدرجة العالية وحدها لا تكفي.

العتبات غير مُتحقَّق منها، والبرنامج ليس للاستخدام السريري.

## شاركوا ما لديكم

انشروا ما صنعتموه في مناقشة جديدة هنا، مع:

- ما هو، في جملة واحدة؛
- لماذا صنعتموه؛
- شيء يُنظر إليه: مقتطف أو لقطة شاشة أو رابط؛
- كيف يمكن لشخص آخر تجربته؛
- نوع الملاحظات التي تريدونها.

استخدموا سجلات مختلقة فقط، وليس بيانات مرضى حقيقية أبدًا. وإن بنيتم على عمل غيركم فانسبوه إلى صاحبه.
