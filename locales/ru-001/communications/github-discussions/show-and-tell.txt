Поделитесь тем, что вы создали: вот модуль сопоставления объясняет запись, которую он не связал бы

Эта категория — для вещей, которые вы сделали с Electronic Patient Record или вокруг него: интеграции, скрипты, демонстрации, руководства и эксперименты. Чтобы показать формат, вот небольшая вещь, которую проект уже умеет.

## Что это

Модуль сопоставления (matcher) — это библиотека на Rust, которая сравнивает две записи идентичности пациента и по каждому полю говорит, почему он связал бы их или нет.

## Зачем он нужен

Связывание двух карт разных людей смешивает их медицинские истории, и это может навредить обоим. Поэтому модуль сопоставления никогда не решает молча. Отсутствующее поле сообщается как отсутствующее, никогда не считается совпадением, а некоторые пробелы вообще блокируют автоматическую связь.

## Попробуйте

Две вымышленные записи: одинаковые фамилия и дата рождения, но у второй нет имени.

```sh
git clone https://github.com/electronic-patient-record/electronic-patient-record.git
cd electronic-patient-record/electronic-patient-record-matcher-with-rust
echo '{"names":[{"family":"Rivera","given":["Alex"]}],"birth_date":"1980-04-12","sex":"female"}' > a.json
echo '{"names":[{"family":"Rivera","given":[]}],"birth_date":"1980-04-12"}' > b.json
cargo run -- a.json b.json
```

Часть вывода:

```json
{
  "score": 1.0,
  "decision": "review",
  "fields": [
    { "field": "family_name", "similarity": 1.0, "weight": 0.25, "note": "similarity 1.00" },
    { "field": "given_name", "similarity": null, "weight": 0.2, "note": "no given name on one or both records" },
    { "field": "birth_date", "similarity": 1.0, "weight": 0.3, "note": "similarity 1.00" }
  ],
  "conflicts": [ "given name not available to confirm the link" ]
}
```

## Что меня удивило

Каждое поле, общее для двух записей, совпадает, поэтому оценка равна 1.0, и всё же модуль сопоставления отказывается их связывать. Он отправляет их человеку, потому что отсутствие имени никогда не может подтвердить связь. Высокой оценки самой по себе недостаточно.

Пороги не валидированы, а программа не предназначена для клинического использования.
