अपनी बनाई चीज़ साझा करें: यहाँ मैचर एक ऐसे रिकॉर्ड को समझा रहा है जिसे वह नहीं जोड़ता

यह श्रेणी उन चीज़ों के लिए है जो आपने Electronic Patient Record के साथ या उसके आसपास बनाईं: इंटीग्रेशन, स्क्रिप्ट, डेमो, ट्यूटोरियल और प्रयोग। प्रारूप दिखाने के लिए, यहाँ एक छोटी चीज़ है जो परियोजना पहले से करती है।

## यह क्या है

मैचर (matcher) एक Rust लाइब्रेरी है जो रोगी की पहचान के दो रिकॉर्ड की तुलना करती है और फ़ील्ड-दर-फ़ील्ड बताती है कि वह उन्हें क्यों जोड़ेगी या नहीं जोड़ेगी।

## यह क्यों है

अलग-अलग लोगों के दो रिकॉर्ड जोड़ने से उनके चिकित्सा इतिहास मिल जाते हैं, और इससे दोनों को नुकसान हो सकता है। इसलिए मैचर कभी चुपचाप निर्णय नहीं लेता। गायब फ़ील्ड को गायब बताया जाता है, कभी मेल नहीं गिना जाता, और कुछ अंतराल स्वचालित जोड़ को सीधे रोक देते हैं।

## आज़माएँ

दो काल्पनिक रिकॉर्ड: वही उपनाम और जन्म-तिथि, लेकिन दूसरे में पहला नाम नहीं है।

```sh
git clone https://github.com/electronic-patient-record/electronic-patient-record.git
cd electronic-patient-record/electronic-patient-record-matcher-with-rust
echo '{"names":[{"family":"Rivera","given":["Alex"]}],"birth_date":"1980-04-12","sex":"female"}' > a.json
echo '{"names":[{"family":"Rivera","given":[]}],"birth_date":"1980-04-12"}' > b.json
cargo run -- a.json b.json
```

आउटपुट का एक हिस्सा:

```json
{
  "score": 1.0,
  "decision": "review",
  "fields": [
    { "field": "family_name", "similarity": 1.0, "weight": 0.25, "note": "similarity 1.00" },
    { "field": "given_name", "similarity": null, "weight": 0.2, "note": "no given name on one or both records" },
    { "field": "birth_date", "similarity": 1.0, "weight": 0.3, "note": "similarity 1.00" }
  ],
  "conflicts": [ "given name not available to confirm the link" ]
}
```

## जिसने मुझे चौंकाया

दोनों रिकॉर्ड के सभी साझा फ़ील्ड मेल खाते हैं, इसलिए स्कोर 1.0 है, और फिर भी मैचर उन्हें जोड़ने से मना करता है। वह उन्हें किसी व्यक्ति के पास भेजता है, क्योंकि गायब पहला नाम कभी जोड़ की पुष्टि नहीं कर सकता। ऊँचा स्कोर अकेला काफ़ी नहीं है।

सीमाएँ सत्यापित नहीं हैं, और सॉफ़्टवेयर नैदानिक उपयोग के लिए नहीं है।

## अपना साझा करें

जो आपने बनाया उसे यहाँ नई चर्चा में पोस्ट करें, इसके साथ:

- यह क्या है, एक वाक्य में;
- आपने इसे क्यों बनाया;
- देखने के लिए कुछ: एक स्निपेट, स्क्रीनशॉट या लिंक;
- कोई और इसे कैसे आज़मा सकता है;
- आप किस तरह की प्रतिक्रिया चाहते हैं।

केवल काल्पनिक रिकॉर्ड इस्तेमाल करें, कभी वास्तविक रोगी डेटा नहीं। और यदि आप किसी और के काम पर निर्माण कर रहे हैं, तो उन्हें श्रेय दें।
