# Access control and consent

RBAC roles (clinician, nurse, pharmacist, allied health, receptionist, clinical admin, patient, proxy, auditor, integrator) plus ABAC (care team / legitimate relationship, encounter, location, purpose of use, security labels), FHIR Consent, national data opt-out, 42 CFR Part 2 via `SUD`, break-the-glass (reason, time-boxed grant, alert, review), proxy and adolescent confidentiality. Evaluated in the service on every read. Tasks SE-1 to SE-6. **Built today (SE-1, 2026-10-21): a role-based route gate on every route, and a policy engine for record-level decisions that no handler calls yet.** The token's `role` attribute (PASETO attrs, or Keycloak realm roles through `role-map.json`) is checked against a table of role × resource × action; a route with no table entry is refused; each refusal is audited. The engine also decides care relationship, security labels, purpose of use, consent and break-the-glass, and is tested across a 0.9-million-request matrix, but consent records, break-the-glass grants and masking (SE-2 to SE-4) are not built, and the table is an unreviewed first draft.

Planned; nothing here is built yet unless stated. Source: [`../../plan.md`](../../plan.md).
