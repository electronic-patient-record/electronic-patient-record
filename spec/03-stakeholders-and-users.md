## 3. Stakeholders and Users

| Role | Needs |
|---|---|
| Clinician (doctor, nurse practitioner) | Fast chart open, concise notes, safe ordering, a manageable inbox |
| Nurse, allied health | Flowsheets, tasks, worklists, medication administration |
| Pharmacist | Medication review, interaction and allergy checks |
| Receptionist / registration | Fast search, duplicate warning, scheduling |
| Patient and proxy | Results, letters, messaging, booking, access log, record download |
| Clinical Safety Officer (a registered clinician) | Hazard log, safety case, release sign-off (DCB0129) |
| Caldicott guardian / privacy officer | Audit review, break-the-glass queue, consent |
| Integrator | Stable FHIR API, SMART apps, Bulk export, HL7 v2 |
| Deployer | Configuration, backups, DTAC/DSPT evidence (DCB0160) |
| Maintainer | One person; accountable for every change ([MAINTAINERS.md](../MAINTAINERS.md)) |
